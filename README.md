# RYCO Coffee House Website

Static React/Vite website for RYCO Coffee House in Moy.

Live site:
https://chrismac860.github.io/RYCOCOFFEESHOPPRACTICE/

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

GitHub Pages deployment is handled by `.github/workflows/deploy.yml`.
